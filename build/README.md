electron-builder reads icons and installer assets from this folder.

`icon.ico` (Windows executable and installer) and `icon.png` (window icon in development) are
generated by `scripts/make-icon.py`, which needs Pillow:

```bat
python -m pip install pillow
python scripts/make-icon.py --text NS --from-color "#ff3fd2" --to-color "#22e6ff" --ico build/icon.ico --png build/icon.png
```

The same script renders a companion icon, for example NeonAmp:

```bat
python scripts/make-icon.py --text NA --from-color "#ffb84d" --to-color "#ff3fd2" --ico build/icon-na.ico --png build/icon-na.png
```
